## Быстрый старт

Все команды запускаются из корня репозитория:

```bash
npm install
npm start
```

## Основные команды

- `npm install`
  Устанавливает зависимости проекта.

- `npm start`
  Запускает target по умолчанию.

- `npm start -- desktop`
  Явно запускает desktop-target.

- `npm start -- --target desktop`
  Именованная форма выбора desktop-target.

- `npm run dev -- desktop`
  Явная dev-команда для desktop-target.

- `npm run check -- desktop`
  Проверяет desktop-часть проекта.

- `npm start -- web`
- `npm start -- mobile`
- `npm start -- server`
  Если эти target-ы ещё не настроены, они должны возвращать понятную заглушку.

## Структура проекта

- `desktop/`

- `web/`

- `mobile/`
